# Changelog

## 0.1.0

First public source release.

### Added

- Reversible audio editing integrated with Subtitle Edit 5.2.0
- Audio/subtitle Undo and Redo coordination
- Original/edited timeline comparison and change navigation
- Adobe Audition round-trip workflow with validation
- Revision and checkpoint handling
- Configurable audio-editing shortcuts
- Batch AI subtitle review with preview and conflict detection
- Glossary, protected-phrase, reference-material, and session support
- Traditional Chinese and English review prompt/response formats
- Reproducible setup, test, and build scripts
- Synthetic and generic public test fixtures
